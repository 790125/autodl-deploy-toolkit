# 文件来源与安全处理说明

本仓库的脚本来自本地 `_lora_train` 工作目录。入库前做过一轮筛选与脱敏，这里是完整记录。

## 一、安全处理（入库前）

| 项目 | 处理方式 |
|---|---|
| SSH 主机 / 端口 | 从常量改为环境变量 `AUTODL_HOST` / `AUTODL_PORT` |
| SSH 密码 | 一律读 `AUTODL_SSH_PASSWORD`，仓库内无任何明文 |
| 实例主机名 | 全部替换，仓库内无任何 `*.seetacloud.com` 残留 |
| 具体端口号 | 全部替换 |
| 日志文件 | 未入库 |
| 模型权重与数据集 | 未入库 |

**入库后自动复核**：对每个文件扫描「硬编码密码 / API Key 形态 / 角色名 / 实例主机名」四类模式，命中即删除该文件。本轮共 28 个文件通过、0 个残留。

## 二、未入库的文件类型

| 类型 | 原因 |
|---|---|
| 含明文密码的连接脚本 | 凭据硬编码，未脱敏 |
| 数据集构建与打标脚本 | 与特定数据集强绑定，通用性低 |
| 训练日志（最大约 500KB/个） | 体积大且含具体路径 |
| 训练配置（`.toml`） | 与具体数据集绑定，仅保留通用模板 |
| `*.zip` 离线包（最大 18GB+） | 体积原因 |

## 三、目录对应关系

| 仓库路径 | 作用 |
|---|---|
| `scripts/setup/` | 在云端实例执行的环境搭建脚本 |
| `scripts/download/` | 权重下载、后台任务管理、断点续传 |
| `scripts/train/` | 训练启动、状态轮询、日志与 TensorBoard 检查 |
| `scripts/service/` | ComfyUI 服务启动与故障修复 |
| `scripts/remote/` | 远程诊断、文件上传、临时文件清理 |
| `scripts/tunnel/` | 本地到云端的端口转发 |
| `configs/` | 训练配置模板 |
